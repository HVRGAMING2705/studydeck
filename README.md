# StudyDeck - Flashcards Quiz App

A fully functional flashcards app that allows users to create decks, flip cards, and take quizzes. A working study app with decks, card flipping, and quiz scoring.

## Features

- Create flashcard decks with questions and answers
- Flip cards to reveal answers
- Quiz mode with score tracking

## Modules

- `studydeck_flashcards_quiz_app`: create_flashcard_decks_with_questions_and_answers, flip_cards_to_reveal_answers, quiz_mode_with_score_tracking

## Tech Stack

React, Tailwind CSS, localStorage
